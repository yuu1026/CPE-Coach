# 可靠教學的驗收門檻

目標是幫初學者依自己的程式完成題目，而非只產生正確答案。以下是待達成的工程／研究驗收條件，不是目前已達成的成績。

## 分開評估三種能力

- 模型本身：關閉參考解答、診斷查表、課程片段替代及計算工具，保留真實對話與程式。
- 完整系統：允許以上工具，但逐輪記錄來源、工具結果、重試、錯誤與耗時；工具輸出不得計入模型獨立成功率。
- 真實學習：學生先做前測，再使用系統，最後獨立完成未看過的相同觀念變形題。不以腳本模擬學生取代這項測量。

## 驗收設計

凍結版本後，為全部49題各準備三條未曾用於提示調整／訓練的路徑：空白起步、部分草稿、含錯草稿。題目可已知，但變數名稱、錯誤組合、追問與測資須另行保留。每條最多12輪，每輪只依實際收到的教學內容修改程式，不偷偷補正確演算法。已用於調整的 Vito 對話只作回歸，不算保留測試。

工程目標：至少95%的完整系統路徑完成，且每題至少一條路徑完成；關鍵教學錯誤（錯誤題意、數學結論、虛構測試通過）為零；每輪程式新增皆可編譯或明確標示尚缺哪些部分；不能把拒答視為正確教學。一次測試沒有錯誤仍不能證明永不出錯。

完成需同時滿足：提供測資與未參與調整的差異測資通過；學生能解釋關鍵變數、條件與邊界；能解一個未見變形題。兩名非資料作者逐輪評分（0至5），每輪至少4分；分歧保留並討論，不由本次修改者單獨宣告高品質。繁體中文、C++17、沿用學生變數、沒有過早交付整題程式亦為必要條件。

記錄每輪與整條路徑延遲、失敗率、重試與工具替代比例。先在目標8GB機器量測，再決定對外等待時間承諾；不以無限重試換取通過。

模型獨立引導是否達標必須另報上述路徑完成率與人工評分。系統通過、模型未通過時，只能宣稱系統輔助教學有效。沒有獨立審查與真實學生測驗時，不宣稱已證實教學成效。

## 本次已做與未做

v23 已將已知 Vito 下一步限制為一項課程新增，移除與片段矛盾的模型旁白；兩次候選仍不符時，明確標記改用系統教學步驟。未改動／啟用失敗的微調權重。

`reports/guided-completion-v23-retry.json`：四輪實際模型請求，僅加入回覆交付的 C++ 片段，每輪在 Docker 編譯，最終通過84組獨立枚舉位置對照案例。四輪來源皆為 `verified_step`，所以模型獨立完成為 false。測試起點已會輸入及 vector，未測真正零基礎，也未測全部49題。`guided-completion-v23.json` 保留服務未啟動的首次連線失敗。

目前不能宣告上述完整驗收達標。需要另行建立保留路徑、獨立評閱與學生研究，不能藉修改已知案例或調低門檻宣告成功。

## 後續回歸紀錄

- `tutoring-vito-v23-live.json` 實際記錄的 `prompt_version` 為 v22：第一次 HTTP 回歸連到尚未重啟的舊網站。檔名不代表部署版本，不能當 v23 成績。
- `tutoring-vito-v23-current.json` 才是九輪 v23。九輪都有回覆、臨時帳號已清除，但偶數案例錯算100／200、對已排序程式錯指中位數、變形題錯算1997，仍未通過教學驗收。讀入草稿的排序步驟已改為正確且明示來源的系統教學。
- `tutoring-vito-v24-even.json`、`tutoring-vito-v25-even.json`、`tutoring-vito-v25-transfer.json` 實際仍連到 v23：終止工具外層程序未停止佔用連接埠的 Python 子程序，故不能當新版成績。已改成核對監聽PID及命令列後重啟，測試工具也會比對資料庫實際 `prompt_version` 與目前程式，版本不合直接失敗。v25 數值檢查改成逐句核對、包含「總和」及跨句明確選址；這只是有限數字語句核對，不是通用數學或語意證明。
- `guided-recovery-v24.json` 首次恢復測試失敗：模擬學習者未依教學明示的「排序之後」插入，而是把 home 放到第一次使用之後。修正測試插入規則後，`guided-recovery-v24-retry.json` 依實際交付的宣告與輸出兩步完成，每步編譯，最終通過84組對照案例。原失敗保留；兩步均是系統課程輔助，不能算模型獨立成功。
- v25 對明確住址的錯誤距離總和重試後仍不合時，顯示具來源標示的工具手算。這是系統修復能力；微調權重仍未啟用，也沒有新的模型獨立成績。
- 真正部署 v25 的 `tutoring-vito-v25-deployed-transfer.json` 正確得到999；`tutoring-vito-v25-deployed-even.json` 避開原本錯誤數字，卻沒有回答怎麼選，而改貼不必要的函式，仍不合格。v26 增加明確數字問題的回答完整性檢查：若未提供工具已核對的所問數值，重試後仍不合就明示改用工具，不把逃避回答算成功。
- `tutoring-vito-v26-even.json` 成功攔下又一次舊版程序殘留（實際v25），清除臨時帳號，沒有計入通過。停止所有已核對的同一環境／命令的網站程序後，`tutoring-vito-v26-final-even.json` 確認實際v26，回覆正確區間2至100、最小總和198，明示由工具替代兩個不合格候選，耗時39.73秒。僅單輪子集成功，不能推成新版九輪或49題全部成功。

本輪軟體檢查：完整122項 Django 測試通過；最後另新增一項「不回答數字、只要求另寫函式」回歸，18項相關政策／投影測試通過。前端草稿／篩選與 Enter／IME／獨立測試／清除對話的兩組 Node 檢查通過。這些都不等於教學驗收通過。未進行新的瀏覽器視覺檢查或獨立教師評閱。
