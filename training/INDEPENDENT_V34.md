# v34 獨立教學能力實測

本次測試固定應用程式在 `5a17232`、`cpe-coach-v34-grounded`，使用正在運行的 Gemma 3 4B IT 與 Docker。測試期間只新增測試工具、模擬請求與報告，沒有調整提示詞、分類規則、教學規則或模型權重來追求通過。

逐輪資料與判讀見 [實測報告](reports/independent-v34-review.md)。這是助理模擬初學者，直接經網站同一套後端服務呼叫本地模型與 Docker；不是瀏覽器點擊驗收、真實學生研究或獨立教師盲評。

## 驗收方式

1. 起步說明與後續解釋須正確，使用者指出矛盾時要能釐清。
2. 提示須能推進目前程式；不能只重述問題或提供無效替換。
3. 所有後續程式變更只能來自實際交付的骨架，或精確採用已驗證候選；不由評估者補演算法。
4. 完成程式要通過題庫與額外測資，再追問理解，而不是把提供完整答案當成教學完成。
5. 系統攔下錯改與真正完成教學分開記錄。模型用到題意重點、既有課程步驟、知識卡或計算工具時均標示。

每條路徑最多五個使用者問題。已明確卡住或出現重大誤導時可提前結束，不以無限重問直到成功作成績。

## 路徑

- Vito 空白起步：只會基本輸入、輸出、迴圈與 vector，先釐清題意，再請求骨架與下一步。
- Vito 自有程式：以平均數選住址，初始測資 1/3；依模型交付逐步修正，不主動提示中位數。
- Hashmat 自有單行程式：固定方向相減，初始測資 1/3；依編譯與測試回饋追問。
- Hashmat 排版對照：前三條路徑暴露單行定位問題後，另開一條只改排版、程式符號一致的探索性對照。不能用它取代失敗的單行路徑，也不能把它當成事先封存的獨立測試集。

額外 Hashmat 測試有四十組輸入，以 Python 整數絕對差作獨立預期值，包含相等、大數與交換順序；打包為一個 judge case。Vito 額外驗證工具以枚舉可能住址作預期值，但只有真正完成的程式才會進入這項額外驗證。

## 工具

`tools/trial_independent_teaching.py` 每次執行一個記錄動作：ask、adopt_scaffold、apply、test 或 extra。程式驗證後才允許 apply；骨架必須是實際交付的一份 C++ main。每輪檢查後端程式雜湊一致，保留真正的 HTTP 請求、原始生成、候選拒絕原因與 Docker 結果。

原始檔案在 `training/reports/independent-v34-*.json`，模擬請求在 `training/reports/independent-v34-inputs/`。未改動實際使用者帳號或學習紀錄。
