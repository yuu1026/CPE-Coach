## 模型回答逐項自評

以下是 GPT/Codex 閱讀原始回覆的自評，未經獨立教師複核。

- 空白引導約 14.66 秒：使用繁體中文，未捏造學生程式；但一次問多個問題，起步可再簡化。
- 分析原程式約 8.70 秒：引用 `int home = addressSum / relatives;`，正確指出平均位置不保證最小距離；後續反問「地址全相同」無法有效區分平均數與中位數。
- 連續追問約 29.05 秒：能沿用 `home`、`addresses`，算出選 2 的距離總和 99、選 34 為 131。但說明將 `103 / 3` 描述為先產生小數再取整，與實際 C++ 整數除法的運算順序不符。
- 完整修正版約 40.80 秒：保留學生主要命名並加入排序，但把 `int home` 宣告在偶數分支的區塊中，奇數分支與後續迴圈卻在外部使用，Docker 確認編譯失敗。回覆仍稱修正後應能正確計算，不能視為可靠解答。

實際錯誤結構：

```cpp
if (relatives % 2 == 0) {
    int home = (addresses[mid - 1] + addresses[mid]) / 2;
} else {
    home = addresses[mid]; // home 不在這個作用域
}
```

本次用於對照、通過測資的手動局部修正為：

```cpp
sort(addresses.begin(), addresses.end());
int home = addresses[relatives / 2];
```

網站可以處理編譯、測試與對話流程；但目前完整解答的回傳流程不會自動編譯模型程式，因此引用檢查、繁體檢查或成功回傳不等於程式正確。這是本次驗證發現的實際限制，未以手動修正的成功結果替代模型的失敗結果。
