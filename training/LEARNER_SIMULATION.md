# 依實際回覆推進的初學者模擬

本次回應「模擬真實使用者學習，讓本地模型依初學者自己的程式修改」。使用現有 Gemma 3 4B IT 與專案教學服務；不是實際招募學生，也沒有以另一個付費模型預先生成老師答案。

## 模擬規則

題目為 UVa10041。模擬者會基本 C++ 輸入輸出、整數運算、for、vector及abs，不預先知道中位數解法。起始程式用 `sum / r` 選住址，使用自己的 `houses`、`r`、`place`、`answer` 變數；並非從正解刪幾行後假裝逐步學會。

每輪先讀取本地模型真正交付的回覆，才撰寫下一輪提問或程式變更。不能自行插入模型尚未教過的核心演算法。若模型誤讀，模擬者可依自己的程式與已執行結果追問。只有模型提出具體修正後才套用，無論修正正確與否，均送受限 Docker 編譯、測試，記錄原始結果。若卡住也保留卡住，不以作者手改的正解冒充模型引導成功。

本輪使用專案現有題意重點、品質檢查與修復機制；`tools/tutoring_step.py` 關閉診斷查表，仍可能使用課程／計算工具，因此逐輪檢查 `source`。這不是完全關閉所有工具的裸模型盲測。現階段直接呼叫應用教學服務，由它以 HTTP 呼叫本地模型；未涵蓋瀏覽器、登入與聊天框操作。

## 紀錄

- 原始請求：`examples/learner-vito-*.json`，每份包含當下完整程式、問題與變更理由。
- 原始實測：`reports/learner-vito-adaptive-20261116.json`，保留模型候選、交付回覆、來源、耗時與 Docker 結果。
- 可讀逐輪對話：`reports/learner-vito-adaptive-20261116.md`，保留修改差異。

初始實測：1/3組題庫測資通過；地址1、2、100算出131，預期99。第一輪模型把place誤讀成1；第二輪錯稱place未影響累加，與原程式矛盾。這些是真實觀察到的模型錯誤，不能當有效提示。

這是已知題目的有限模擬，既不能證明全部49題可用，也不能替代真實初學者前後測。

## 連續學習過程的觀察

先後8次要求提示／局部修正，並沒有順利完成：

| 階段 | 模型實際交付／模擬者動作 | 實測 |
| --- | --- | --- |
| 起始 | 平均數 `sum / r` | 1/3通過 |
| 引用自己的原碼追問 | 模型誤讀place的值、誤稱沒有影響answer | 不修改原碼，要求釐清 |
| 要求最小替換 | 模型要求把原行換成相同一行 | 仍1/3 |
| 第5次詢問 | 給 `int place = houses[r / 2];`，未教sort呼叫 | 只套用該行後2/3 |
| 第6次詢問 | 說明需要algorithm標頭與排序，但未給呼叫語法 | 僅加入明確指定的標頭，再追問 |
| 第7次詢問 | 指示將place搬到讀入之前 | 照做後0/3 |
| 第8次詢問 | 給sort語法，卻要求放在main開頭 | 照做後houses未宣告，編譯失敗 |
| 第9次詢問 | 使用者明確要求完整修正自己的程式 | 兩個候選仍無法編譯，系統擋下；未套用未交付候選 |

因此本次連續提示教學路徑判定失敗，而非「差一步成功」。第10次詢問另外模擬清除對話、保留同一份失敗程式再請求完整修正，以觀察舊錯誤歷史的影響；即使這個對照能修好，也不能回頭把原教學路徑判為成功。

上述紀錄只用於測試與分析，沒有加入模型訓練集，也沒有更換或啟用微調權重。

## 模擬發現並修正的系統問題

第10次使用者說「給我完整修正後的C++」，舊版意圖辨識沒有把語言名稱當作程式，仍套用提示模式，將完整候選擋下。這是系統政策錯誤，不能全部歸因於模型。已修正 `requests_solution`；明確否定與只要求C++片段／範例仍維持提示模式，並補回歸案例。

第11次使用同一問題、同一份失敗程式與清空歷史，在修正後的v27重試，已確認 `response_mode=solution`；但模型候選仍未通過測資（單一親戚與全部同址應為0，候選輸出3／10）。系統擋下，使用者程式未被這些候選覆蓋。這個對照同時涉及政策修正，不能用來宣稱單純清空歷史能解決問題。

最後第12次模擬使用者撤銷助理造成的修改、回復原始平均數草稿，再清空歷史要求完整修正。這是另一次有界恢復對照，仍不是原連續提示路徑成功。

## 最後結果

第12次仍失敗：候選宣稱使用排序後中位數，實際程式卻沒有呼叫sort；對10、100、1輸出189而非99，已被系統測資檢查擋下。沒有將這份候選套用到學生程式。最後重測學生回復的原始草稿，仍1/3通過。

共12次使用者詢問、19次實際本地模型生成（含系統的一次重試）、6次學生程式Docker測試。5次詢問未能交付合格回覆，其餘7次有交付也不表示內容正確。教學服務請求累計532.38秒，包含重試、格式處理與完整程式檢查，不能當純模型推論時間。完整答案候選另經系統內部Docker驗證，不包含在上述6次學生測試次數內。

**本次模擬未能引導初學者完成程式。** 沒有執行成功後的新測資泛化評估，也沒有真實學生學習測驗。已證實可保留學生變數、交付局部片段，並能擋下部分錯誤完整答案；但教學仍有誤讀、無變更修正、漏前置步驟、錯誤放置位置及旁白與程式不符。不能宣稱已可靠。

本輪修正僅為完整C++請求辨識與可重現的模擬／報告工具，沒有聲稱修好上述所有模型語意錯誤。軟體檢查：123項Django測試通過；最後的片段／範例保護另以11項相關測試通過；前端 Enter／IME／測試與聊天分離／清除對話檢查通過。網站已載入v27，模型健康檢查200、網站匿名入口302導向登入。未進行瀏覽器視覺QA。

```powershell
python tools/tutoring_step.py --request training/examples/learner-vito-02.json --report training/reports/learner-replay.json
```

