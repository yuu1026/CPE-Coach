# 自然提問模式

使用者直接在聊天框提出需求，不再選擇第一、第二或第三層提示。模型依最新問題、目前程式與對話進度調整解釋深度。

| 問法 | 系統處理 |
|---|---|
| 我完全沒有想法 | 從小例子開始，推進一個可操作步驟 |
| 給我程式雛型／骨架 | 允許必要標頭與 main，核心邏輯留 TODO；以 Docker 檢查編譯，不跑題目測資 |
| 請手算確認，不要改程式 | 回答數值與觀念，不強制引用目前程式 |
| 幫我修改目前程式 | 沿用原碼提出局部修改，在副本編譯、測試與檢查退步，再由使用者決定套用 |
| 給我完整修正後的 C++ | 允許完整程式，使用既有完整解答驗證流程 |

內部的骨架、完整答案與修改判斷只用於選擇驗證方式，並非提示等級。自然語言辨識仍可能誤判；相關規則在 `coach/conversation_policy.py`。

舊紀錄中的 `hint_level` 保留以相容既有資料，預設為 1；它不再傳給模型，也不影響畫面與回答。舊版實驗腳本的參數仍可使用，但層級值不再影響推論。

失敗回覆會保存候選與拒絕原因，追問「再試一次」可承接先前未完成的請求。CSS、聊天草稿、選題、測試與詢問分流沿用目前機制。

## 啟動

停止原本網站後，在專案資料夾執行 `./啟動網站-真實模型.ps1 -BaseModel`，再以 Ctrl+F5 重新整理頁面。啟動腳本會自動更新資料庫。模型服務如未運行，另開終端機執行 `./啟動模型.ps1 -BaseModel`。
